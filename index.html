Webflow webhooks · Edge functions

Only act on webhooks that really came from Webflow.

Form submissions, CMS changes and orders arrive as signed POST requests. This router checks the HMAC signature, rejects replays older than 5 minutes, ignores Webflow's retries once an event has been handled, and routes each event by triggerType. The buttons below run the real router code in your browser.

Deploy

    
npx wrangler secret put WEBFLOW_WEBHOOK_SECRET   # the webhook's secret, or your OAuth app's client secret
npx wrangler secret put SLACK_WEBHOOK_URL        # optional
npx wrangler deploy                              # → https://…workers.dev/webhooks/webflow

# or on any Node 20+ host
WEBFLOW_WEBHOOK_SECRET=… node src/node-server.js

    
Register the endpoint with POST /v2/sites/{site_id}/webhooks. Webhooks created in the Webflow dashboard aren't signed, so they can't be verified.
